ONYX-Pro Firmware Builder v0.1.5 for macOS

1. Keep these files together in the same folder:
   - ONYX-Pro_Firmware_Builder_v0.1.5.py
   - ONYX-Pro_Firmware_Builder_Mac.command
   - INSTALLATION_GUIDE.txt

2. Double-click ONYX-Pro_Firmware_Builder_Mac.command to launch the app.

3. If macOS blocks it the first time:
   - Control-click the .command file and choose Open.
   - Confirm Open in the security dialog.

Requirements:
- Python 3
- Arduino CLI
- Arduino-Pico core installed in Arduino CLI

The Python Builder itself is unchanged. Windows users can continue
double-clicking the .py file as before.
